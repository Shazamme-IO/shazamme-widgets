Add a tab called "Contact" to the Content Editor of this widget. Add these fields to that tab only. Keep the keys exactly as written. Show phone and Show email are already on the Card tab; these fields add the mobile and choose icon or text for each line.

**Tab: Contact**

Phone
- Phone icon | key: showPhoneIcon | type: toggle | default: false | help: A phone icon before the number. Used when Show phone is on.
- Phone number text | key: showPhoneLabel | type: toggle | default: true | help: Off shows the icon only.
- Phone name | key: phoneText | type: text | default: Phone | help: With the icon only, screen readers say this before the number, for example "Phone: 02 9999 0000".

Mobile
- Show mobile | key: showMobile | type: toggle | default: false | help: The consultant's mobile number as its own line. When it is on, the phone line shows only the phone number.
- Mobile icon | key: showMobileIcon | type: toggle | default: false | help: A mobile phone icon before the number.
- Mobile number text | key: showMobileLabel | type: toggle | default: true | help: Off shows the icon only.
- Mobile name | key: mobileText | type: text | default: Mobile | help: With the icon only, screen readers say this before the number.

Email
- Email icon | key: showEmailIcon | type: toggle | default: false | help: An envelope icon before the address. Used when Show email is on.
- Email address text | key: showEmailLabel | type: toggle | default: true | help: Off shows the icon only.
- Email name | key: emailText | type: text | default: Email | help: With the icon only, screen readers say this before the address.
