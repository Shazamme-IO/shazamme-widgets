Build the Design Editor for this widget. Every line is one style a site builder can change. Keep the selectors and properties exactly as written. Group under the headings.

**Tags**

- Tag text colour | selector: .shm-tc .shm-tc-pill | property: color | default: #101920
- Tag background | selector: .shm-tc .shm-tc-pill | property: background-color | default: transparent
- Tag border colour | selector: .shm-tc .shm-tc-pill | property: border-color | default: #1ba9cc
- Tag border width | selector: .shm-tc .shm-tc-pill | property: border-width | default: 2px
- Tag corner radius | selector: .shm-tc .shm-tc-pill | property: border-radius | default: 30px
- Tag text size | selector: .shm-tc .shm-tc-pill | property: font-size | default: 18px
- Tag text weight | selector: .shm-tc .shm-tc-pill | property: font-weight | default: 400
- Tag padding | selector: .shm-tc .shm-tc-pill | property: padding | default: 2.5px 15px

**Spacing and alignment**

- Gap between tags | selector: .shm-tc .shm-tc-list | property: gap | default: 12.5px
- Tag alignment (flex-start, center, flex-end). Applies only when Columns is 0 (free wrap); in a column grid every tag fills its cell | selector: .shm-tc .shm-tc-list | property: justify-content | default: flex-start
- Space between groups | selector: .shm-tc .shm-tc-group | property: margin-bottom | default: 50px

**Hover (linked tags only)**

- Hover text colour | selector: .shm-tc a.shm-tc-pill:hover | property: color | default: #101920
- Hover background | selector: .shm-tc a.shm-tc-pill:hover | property: background-color | default: #1ba9cc
- Hover border colour | selector: .shm-tc a.shm-tc-pill:hover | property: border-color | default: #1ba9cc
- Keyboard focus ring colour | selector: .shm-tc a.shm-tc-pill:focus-visible | property: outline-color | default: #101920
- Keyboard focus ring outer colour (a halo so the ring shows on dark and light backgrounds) | selector: .shm-tc a.shm-tc-pill:focus-visible | property: box-shadow | default: 0 0 0 5px #ffffff
